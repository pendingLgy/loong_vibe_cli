# 🧩 Available Skills Index (可用技能清单)

所有专业技能均已预加载至内存中，**无需扫描本地文件夹路径**。当任务场景匹配时，仅需通过传递对应的 **`skill_name`** 即可直接按需获取其完整规范内容。

目前已注册的可用技能清单：

* **plan**: 适用于复杂编码、多文件修改、重构或新功能开发时，用于生成包含工作目标的结构化工作计划，并持久化保存到当前工作目录下 `.vcl/plans/` 中。
* **code_generation**: 适用于根据用户需求编写新代码、实现新模块或重构现有代码时的专业编码指导规范（遵循现代语法、实用边界与规范输出）。
