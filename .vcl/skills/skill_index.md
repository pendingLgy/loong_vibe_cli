# 🧩 Available Skills Index (可用技能清单)

当前工作区已注册以下专业技能。当用户的任务与某个技能的触发场景匹配时，请优先参考对应规范进行处理：

* **coding_work_plan**: 适用于复杂编码、多文件修改、重构或新功能开发时，用于生成包含工作目标的结构化工作计划，并持久化保存到当前工作目录下 `.vcl/plans/` 中。
* **code_generation**: 适用于根据用户需求编写新代码、实现新模块或重构现有代码时的专业编码指导规范（遵循现代语法、实用边界与规范输出）。
